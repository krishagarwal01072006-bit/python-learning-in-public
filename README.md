# 🐍 Python — Learning in Public

My Python learning journey, documented on LinkedIn every 2 days as I work toward getting into AI.

Each folder holds the runnable mini-projects from one post in the series:

| Folder         | LinkedIn post topic                              |
|----------------|--------------------------------------------------|
| fundamentals   | Day 1 — comments, variables, keywords, operators  |
| conditionals   | Day 3 — if/elif/else, truthiness                  |
| loops-part-1   | Day 5 — for loops, range()                       |
| loops-part-2   | Day 7 — while loops, break/continue              |
| lists          | Day 9 — lists, indexing, slicing                 |
| dictionaries   | Day 11 — dicts, keys, get(), iteration           |
| functions      | Day 13 — def, parameters, return, scope          |
| comprehensions | Day 15 — list/dict comprehensions, lambdas       |
| exceptions     | Day 17 — try/except, tracebacks                  |
| file-handling  | Day 19 — open(), with-statement, JSON            |

Every script runs as-is: `python3 <script>.py`
